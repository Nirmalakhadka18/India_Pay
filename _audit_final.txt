4. FUNCTIONAL VERIFICATION (PHASE 3 HIGHLIGHTS)
--------------------------------------------------------------------------------
Verified via synthetic harness against the REAL computeEmployeePayrollItem /
computeProfessionalTax / computeLabourWelfareFund implementations:

PF CONTRIBUTION MATRIX
  - Basic Rs 15,000 (full month): EE PF 1800, EPS 1250 (capped), ER EPF 550,
    EDLI 75, Admin 75. Total employer = 1950 + ESI where enabled.
  - Basic Rs 25,000 WITHOUT voluntary election: wage restricted to Rs 15,000
    statutory ceiling - identical output to Rs 15,000 case.
  - epfOnActualBasic=true: EE 3000 (12% of Rs 25,000), EPS still capped 1250,
    ER EPF 1750, EDLI still capped at Rs 15,000 wage (75), Admin 125.
  - epfOptOut=true: all PF/EPS/EDLI/Admin zero even when EPF enabled workspace.

ESI
  - Gross Rs 20,000: EE 150 (0.75% ceil), ER 650 (3.25% ceil). Net deducts EE only.
  - Boundary: Rs 21,000 GETS ESI; Rs 21,001 does not.
  - LOP-adjusted earned wage used (gross - LOP deduction).
  - Section 2(9) proviso: employee crossing Rs 21,000 mid contribution period
    with esiContributionPeriodCovered=true stays covered, warning emitted.
  - Without the proviso flag: no ESI above threshold.

PROFESSIONAL TAX
  - Karnataka: Rs 24,999 exempt; Rs 25,000 -> Rs 200 (non-Feb), Rs 300 (Feb).
  - Maharashtra male: <=7500 nil; <=10000 Rs 175; >10000 Rs 200 (Feb 300).
    Female: <=25,000 nil; >25,000 Rs 200 (Feb 300).
  - Telangana / AP: <=15,000 nil; <=20,000 Rs 150; >20,000 Rs 200.
  - Nil-PT states (Delhi, Haryana, Rajasthan, UP, HP, Punjab, Chandigarh,
    Uttarakhand, Goa): Rs 0 with zero deductions.
  - Missing state: Rs 0 + explicit warning. Unrecognized state: Rs 0 + warning,
    NEVER defaults to Karnataka slabs.

LOSS OF PAY
  - calendar_days basis: daily = gross / days-in-month (30-day test month).
  - fixed_30_days basis: uses /30 even for 31-day months (round(31000/30)=1033).
  - unpaid_leave and absent respected via lopSettings flags; half_day uses
    halfDayFactor (0.5). present / paid_leave produce zero LOP.
  - includeAbsent=false correctly excludes absents.

Rounding / edge cases
  - Zero gross with missing salary structure: hasSalaryStructure=false,
    warning present, everything Rs 0.
  - Fractional basic (10,000.55): PF rounded to whole rupee per line item.
  - Very large salary (Rs 1e9): no arithmetic overflow/NaN.
  - Over-deduction (LOP + custom > gross): total deductions computed exactly,
    net salary floors at Rs 0 (never negative).

TOTALS-RECONCILIATION INVARIANT (verified)
  netSalary = grossSalary - lopDeduction - totalCustomDeductions
              - totalStatutoryDeductions   (employer contributions NEVER
                                            deducted from employee net pay)
  and statutoryDeductions/employerContributions line items sum exactly to their
  total fields; basic + allowance amounts sum exactly to grossSalary.
