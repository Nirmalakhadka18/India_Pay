3. PROBLEMS RESOLVED DURING THIS SESSION
================================================================================

1. Problem: 394 empty dependency directories on Drive E:
   Root Cause: E: is an exFAT volume. Bun requires NTFS directory junctions 
   to link @v1/* workspace packages into node_modules. Bun crashed with EISDIR.
   Solution: Set up clean working copy on NTFS volume (D:). Ran bun install 
   using frozen lockfile without altering package versions or dependencies.

2. Problem: TS2783 Duplicate employeeId in packages/backend/convex/payroll.ts
   Root Cause: getPayslip query explicitly set 'employeeId: args.employeeId' 
   directly before spreading '...item', which already contains employeeId.
   Solution: Removed redundant property assignment; preserved payload integrity.

3. Problem: 6 Biome style errors in apps/app/src/lib/payslip-pdf.ts
   Root Cause: Default parameter types flagged under noInferrableTypes, unneeded 
   let variable under useConst, and string concatenation under useTemplate.
   Solution: Removed explicit redundant types (lineWidth = 1, fontSize = 10), 
   switched to const header, and used string interpolation template literals.

4. Problem: TS2307 Cannot find module 'vitest' in apps/app/tsconfig.json
   Root Cause: apps/app tsconfig included all **/*.ts files while only excluding 
   node_modules, causing Next.js compiler to check unit test files without Vitest types.
   Solution: Updated apps/app/tsconfig.json exclude field to include 
   "**/*.test.ts" and "**/*.test.tsx".
