5. CRITICAL SECURITY & BACKEND AUDIT
--------------------------------------------------------------------------------
1. Authentication Enforcement:
   Every operational query and mutation in orgs.ts, workspaces.ts, employees.ts,
   salaries.ts, payroll.ts, and reports.ts begins with getAuthUserId(ctx) and throws
   ConvexError("Not authenticated") if unauthenticated.

2. Workspace Isolation:
   Queries enforce workspace scoping via indexed database filters:
   .withIndex("by_workspace", q => q.eq("workspaceId", args.workspaceId)).
   Access control helper requireMember(ctx, userId, workspaceId) ensures users from
   one tenant cannot query or mutate records belonging to another tenant.

3. Data Masking Compliance:
   In reports:generateReportData and employee profile APIs, sensitive fields (pan,
   bankAccountNumber, ifscCode) are masked (••••1234) for non-admin viewers.
   Only users holding the verified admin role in members receive unmasked banking data.

4. Convex Deployment Health:
   - Target deployment: dev:basic-bobcat-92 (https://basic-bobcat-92.convex.cloud)
   - Function bundling: Succeeded (npx convex dev --once ready in 7.57s)
   - Registered generated API: api.workspaces and api.systemSettings active.
